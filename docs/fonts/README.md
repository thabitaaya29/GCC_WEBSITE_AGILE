# Font research GCC

Tanggal pengecekan: 28 Oktober 2026.

## Apple Garamond

Sumber: https://www.dafont.com/apple-garamond.font

Arsip asli: `downloads/apple-garamond.zip`.
Hasil ekstraksi: `apple-garamond/`, berisi enam TTF: Regular, Italic,
Bold, Bold Italic, Light, dan Light Italic.

Arsip yang diunduh tidak menyertakan dokumen lisensi. Keberadaan tautan
unduhan tidak membuktikan izin self-hosting atau pemakaian pada website GCC.
File disimpan sebagai referensi, belum diimpor oleh aplikasi.

## BUDGET

Font bernama Budget di https://www.cufonfonts.com/font/budget dikategorikan
handwritten sehingga belum dapat dianggap cocok dengan sans-serif pada VISGUIDE.png.

Kandidat sans-serif: Budget 2012:
https://www.ffonts.net/Budget-2012.font

Identitas kandidat belum dikonfirmasi sebagai font dalam visual guide.
Percobaan download dari FFonts diblokir challenge JavaScript/cookies;
belum ada file Budget yang berhasil disimpan. Situs mencantumkan personal use;
izin web untuk GCC belum dikonfirmasi.

## Status aplikasi

Fallback pada `src/styles/global.css` tetap digunakan. Tidak ada font pengganti
yang diberi nama BUDGET atau Apple Garamond. Sebelum aktivasi, cocokkan file
BUDGET dengan sumber desain GCC dan pastikan izin penggunaan web kedua font.
